How it is built

A small stack I can run and debug on my own.

Stack

  • Python
  • FastAPI
  • JavaScript
  • WebSockets
  • Solana RPC
  • PostgreSQL
  • Supabase
  • Docker
  • Render

Decisions

  • Live token launches stream in over WebSockets and Solana RPC, merged with several market-data APIs.
  • Each token gets its own candlestick chart built from raw tick data.
  • The paper engine simulates fees and slippage, set pessimistically.
  • Token snapshots and outcomes are saved to PostgreSQL on Supabase, so findings survive redeploys.
  • A chart-pattern lab tests entry rules on historical candles without look-ahead bias.
